# 公开副本与原始证据

主分支保留代码、配置模板和经过核验的聚合结果。`research` 分支额外保留手稿、对话轨迹、日志和接受记录，包括失败、未提交结果和质量退化。

公开副本替换了内部路径、地址、部署 ID、实例身份与镜像地址。实例采用稳定匿名标签，因此仍能区分原训练和独立重放；数值、时间、错误性质、checkpoint／delta／恢复对象的原始 SHA256 保留。凭据、私钥、系统／开发者指令和工具响应体没有作为对话发布。

**哈希含义需要区分：**

- 历史 `config_hash`、blob SHA256 和 `source_sha256` 标识实际运行时的输入、对象和代码。
- 公开配置修改了路径和身份，不能按该副本重新计算出原始 `config_hash`；重新运行应生成自己的配置身份。
- `PUBLIC_EXPORT_MANIFEST.json` 标识研究分支中公开副本文件的哈希，不是原运行文件哈希。
- 模型权重、Adam tensor 和 token 数据体不放进普通 Git 仓库；公开文件保留内容寻址引用、字节数、来源固定 revision 和审计结论。

对话导出只覆盖导出时能读取的相关会话文件；保留可见用户／助手文本及工具名称，不发布工具参数和工具响应体。它不是未存储历史的补写，也不把注入式历史摘要当成用户对话。

发布过程由代码助手协助。实测结论以接受记录、完整验证、独立恢复比较和状态审计为依据；源码检查、资源申请或容器启动不能替代真实 GPU 结果。
